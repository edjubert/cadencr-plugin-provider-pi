## Cadencr mark

(`packages/brand/src/svg/mark.mjs` in the Cadencr repository): the 12-dot
ring geometry, the emerald core and the graphite/ink/emerald color tokens are
reused. The size of each ring dot encodes a digit of π (3.14159265358), and
the "Pi" label uses standard sans-serif lettering with a dotless i in the core.

## Pi

The name "Pi" in `icon.svg` identifies the Pi coding agent
(https://github.com/earendil-works/pi), an independent open-source
project by earendil-works. It is rendered as ordinary text, without reusing
the official Pi logo's artwork.

`pi-logo.svg` reproduces the official Pi logo from
